# Task Management REST API

A REST API for managing user tasks with JWT authentication.

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt

## Features

- User registration
- User login
- JWT authentication
- User profile
- Create tasks
- View tasks
- Search tasks
- Filter tasks
- Pagination
- Update tasks
- Delete tasks
